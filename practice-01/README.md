**Объяснение различия `typeof document`:**

`document` — это объект, который даёт браузер для работы с HTML-страницей. Это часть Browser API, а не самого языка JavaScript. В браузере этот объект есть, поэтому `typeof document` даёт `"object"`. В Node.js HTML-страницы нет, объекта `document` тоже нет, поэтому `typeof document` даёт `"undefined"`. То есть язык один, а среды выполнения разные, и набор доступных объектов у них разный.
